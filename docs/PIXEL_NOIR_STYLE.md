# 鹅工具箱：像素夜航风格说明

## 1. 这套风格叫什么

最准确的中文名称是：**电影感像素夜景（Cinematic Pixel Noir）**。

结合鹅工具箱自身的气质，也可以使用更具品牌辨识度的名称：**像素夜航 / Goose Lab After Dark**。

它不是单纯的“复古像素风”，而是以下几种视觉语言的混合：

- **像素艺术**：所有角色、建筑与光影都由可辨识的像素簇构成，保留手工绘制的边缘节奏。
- **黑色电影式低照度**：大面积深色留白、小范围聚光、强烈明暗分区，画面像夜间电影剧照。
- **舒适型赛博奇幻**：使用紫色、青色设备光，但不追求喧闹城市霓虹；科技只是工作室里的工具。
- **独立游戏叙事界面**：画面不是装饰插图，而像游戏开场、任务大厅和章节结尾，天然带有故事。
- **吉祥物群像设计**：五只鹅不是五个重复图标，而是拥有岗位、道具和状态的“夜班员工”。

一句话描述：

> 一间只在深夜营业的像素工具工坊，五只鹅在琥珀灯、紫色门廊和青色设备光之间安静地发版。

## 2. 视觉情绪

这套风格的核心不是“炫”，而是四种情绪同时存在：

1. **神秘**：深靛黑背景和大面积不可见区域，让访客感觉工坊藏在城市或系统深处。
2. **温暖**：鹅的圆润轮廓、琥珀灯和小道具，抵消深色环境可能带来的冷漠。
3. **专注**：角色都在排队、记录、调试或发布，不是无目的地摆拍。
4. **期待**：门廊、队伍、状态灯和工具箱不断暗示“下一次构建马上开始”。

它适合鹅工具箱，是因为项目本身就具有“个人开发者 + 多个小工具 + 高频发版 + 温和文案”的叙事基础。

## 3. 构图语言

### 3.1 大留白，小舞台

画面只让 35%–55% 的区域承载角色和环境，其余区域保持深色、低细节，用来放标题和操作入口。

这不是“内容太少”，而是舞台灯光式构图：只有被灯照到的地方才属于当前剧情。

### 3.2 角色群像不是卡片网格

五个产品不再依赖五张完全相同的卡片。首屏将它们画成排队进入工坊的五位员工；正文再用列表逐一说明职责。

这样可以同时获得：

- 首屏的品牌记忆点；
- 正文的可读性；
- 产品之间“属于同一宇宙”的联系；
- 避免普通 SaaS 落地页的卡片模板感。

### 3.3 章节像游戏场景切换

- 首屏：工坊门口，角色集合，建立世界观。
- 方法区：室内工作台，解释如何设计和发版。
- 动态区：发版日志，承担信息密度。
- 结尾：通往星光的门，邀请访客进入下一次构建。

## 4. 色彩系统

### 4.1 基础色

| 角色 | 色彩方向 | 用途 |
|---|---|---|
| 夜幕底色 | 近黑深靛蓝 | 页面主背景、最大面积留白 |
| 抬升表面 | 深蓝紫 | 导航、菜单、悬停行、工作台框架 |
| 主文字 | 微暖灰白 | 标题、关键说明，避免纯白刺眼 |
| 次文字 | 低饱和蓝灰 | 正文、辅助标签、时间信息 |

### 4.2 光源色

| 光源 | 情绪 | 使用原则 |
|---|---|---|
| 琥珀黄 | 人的温度、正在工作 | 主按钮、工作灯、关键标题强调 |
| 门廊紫 | 未知、下一章节 | 场景深处、阴影轮廓、硬投影 |
| 仪器青 | 技术、实时反馈 | 状态、特效选中、系统标签 |
| 珊瑚橙 | 发版、警示、活力 | 小面积指示灯和高优先级细节 |
| 状态绿 | 在线、构建成功 | 只用于真实状态，避免装饰性滥用 |

颜色不平均分配。深靛黑约占 70%–82%，所有发光色合计不超过 18%。这正是画面“克制但不无聊”的原因。

## 5. 光影与材质

### 5.1 三类光源

- **琥珀实用灯**：来自台灯、壁灯，照亮鹅的脸和工作台。
- **紫色环境光**：来自门廊、设备深处，负责塑造世界观。
- **青色轮廓光**：来自终端和雷达，让角色从深色背景中分离。

### 5.2 材质关键词

- 潮湿石地面的低亮度反射；
- 旧金属、粗糙砖墙和电缆；
- 软质鹅绒与硬质设备形成反差；
- 小型发光屏幕和状态灯，不做大面积霓虹牌。

## 6. 像素艺术规则

- 使用清晰的 32-bit 像素艺术，而不是 8-bit 极简符号。
- 轮廓由可见的阶梯状像素簇组成，不使用模糊描边。
- 网页中的场景图启用 `image-rendering: pixelated`，缩放时保持边缘性格。
- 角色尺寸足够大，移动端裁切后仍能看清道具。
- 不在生成图里放文字；所有真实文案由 HTML 渲染，保证可访问性、清晰度和可维护性。

## 7. 字体系统

这套界面采用“现代正文 + 少量像素标签”的组合，而不是整页像素字体。

- **主标题：Geologica**。几何骨架强、重量足，能承接电影海报式标题。
- **中文正文：Noto Sans SC**。阅读稳定，不让像素艺术牺牲内容可读性。
- **系统信息：JetBrains Mono**。用于版本、日期、技术标签。
- **章节状态：Silkscreen**。只用于短英文标签，如 `SHIP LOG`、`LIVE FEED`、`SIGNAL FX`。

像素字体只能用于短标签。中文正文如果全部像素化，会降低阅读速度，也会让界面退化成游戏 HUD。

## 8. 组件形状

- 圆角控制在 2–7px，避免柔软的 SaaS 胶囊感。
- 主按钮使用 4px 硬投影，按下时位移 3px，像实体街机按钮。
- 信息区优先使用横向日志行、章节画面和设备面板，不依赖圆角卡片网格。
- 标签使用小矩形和单像素边框；只有状态类标签可以拥有发光色。
- 插图容器使用 1px 亮边 + 8px 无模糊硬投影，模拟游戏窗口和设备屏幕。

## 9. 动效语言

### 9.1 页面动效

- 状态灯使用阶梯式闪烁，不使用柔软呼吸光。
- 按钮悬停和按压使用分段位移，模拟像素帧。
- 章节进入采用轻微裁切揭示和上移，不让所有内容同时淡入。
- 跑马灯用于表现“持续构建”，速度稳定，不使用弹性运动。

### 9.2 Canvas UI

Canvas 特效保留为“实验室信号层”，而不是盖住像素场景：

- 默认流体强度降低，作为指针轨迹；
- 涟漪对应点击反馈；
- 云雾对应工坊环境；
- 故障对应广播和构建状态；
- 抖动对应像素透镜。

所有特效遵循系统的减少动态效果设置。没有 WebGL 时，场景图和内容仍完整可用。

## 10. 三张原创场景资产

### `goose-lab-hero.webp`

五只鹅在秘密工坊门口排队。左侧大面积深色留白承载主标题；右侧用琥珀灯、紫色门廊和湿地反射建立世界观。

### `goose-lab-workbench.webp`

单只鹅在深夜工作台发布软件。画面包含终端、雷达、版本盒、笔记本和 2FA 道具，映射项目的真实开发方式。

### `goose-lab-portal.webp`

一只提着工具箱的鹅走向星光门廊。它承担结尾 CTA：既像离开工坊，也像进入下一次构建。

## 11. 实现边界

为了避免“像素风”变成廉价游戏皮肤，项目坚持以下边界：

- 不把所有文本改成像素字体；
- 不使用满屏霓虹和赛博朋克城市；
- 不堆叠扫描线、噪点、CRT 弯曲等复古滤镜；
- 不让 Canvas 特效覆盖角色面部和正文；
- 不复刻参考图中的原角色、门廊或品牌元素；
- 不用 AI 生成图承载需要准确表达的文字；
- 保证移动端裁切、正文对比度和减少动态效果体验。

## 12. 最终风格定义

**类型：** 电影感像素夜景 / 舒适型赛博奇幻 / 独立游戏叙事界面。

**品牌名：** 像素夜航（Goose Lab After Dark）。

**视觉公式：**

> 72% 深靛黑留白 + 12% 琥珀工作灯 + 8% 紫色门廊 + 5% 青色设备光 + 3% 珊瑚状态灯，再加五只认真上夜班的鹅。
